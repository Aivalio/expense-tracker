# 💰 Expense Tracker

A full-stack expense tracker built with **FastAPI**, **PostgreSQL** and **Vanilla JavaScript**.

![Status](https://img.shields.io/badge/status-under%20construction-yellow)

## 🚧 Status

Under construction — started October 2026.

## 🛠️ Planned Tech Stack

**Backend:** FastAPI · SQLAlchemy 2.0 · PostgreSQL (Neon) · JWT · bcrypt
**Frontend:** HTML5 · Tailwind CSS · Vanilla JavaScript · Chart.js
**Testing:** pytest · Jest
**DevOps:** Docker · GitHub Actions · Render · Vercel
